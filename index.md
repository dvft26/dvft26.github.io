# Website Overview Studio

Website Overview Studio is the software that prepares short, fact-checked overview videos of public websites and publishes them to the **TutorialLore** YouTube channel ([youtube.com/@Tutorial_Lore](https://www.youtube.com/@Tutorial_Lore)), which is owned and operated by TutorialLore.

- Each video explains what a website is and what it offers, using facts checked against the website's own pages.
- Videos are uploaded through the **YouTube API Services**, only to channels owned by TutorialLore, with the owner's authorization.
- The software is not offered to the public: only the channel owner signs in.
