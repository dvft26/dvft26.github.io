# How to edit this website (no coding needed)

This repository is the public website for **Website Overview Studio**: homepage, privacy policy and terms. GitHub publishes it automatically.

## To change a page

1. Open the file on GitHub: `index.md` (homepage), `privacy.md` (privacy policy) or `terms.md` (terms).
2. Click the **pencil icon** (Edit this file) at the top right of the file.
3. Change the text. Lines starting with `#` are headings; `**text**` is bold; `[words](address)` is a link.
4. Click **Commit changes…**, then **Commit changes** again.
5. Wait about a minute, then refresh the website.

## Rules to keep

- Keep the links to the **YouTube Terms of Service** and the **Google Privacy Policy**; Google requires them.
- If you change what the app does with YouTube data, update the privacy policy and its **Last updated** date.
- Never put passwords, API keys or other secrets in these files. Everything here is public.
